PSIKIANOTAS CLÍNICA v2.3 — PWA PARA ANDROID

1. Sube el contenido de esta carpeta a tu sitio HTTPS (por ejemplo, el GitHub Pages donde tengas PsikiaNotas).
2. Abre la URL en Chrome Android.
3. Menú ⋮ > "Instalar aplicación" o "Añadir a pantalla de inicio".
4. Se abrirá como app independiente y quedará disponible offline después de la primera carga.

Para probar sin subir nada, abre index.html; la interfaz funciona, pero la instalación PWA y el service worker requieren servirla por HTTPS (o localhost).
